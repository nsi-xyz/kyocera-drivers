Imprimer sur l'imprimante Kyocera FS-1220MFP

Guide de configuration — Chromebook, Windows, Android, iPhone / iPad

L'essentiel en une ligne

L'imprimante est branchée en USB au PC um560 (Debian), qui la partage sur le réseau local. Depuis n'importe quel appareil du même réseau, ajoutez l'imprimante à l'adresse :

ipp://192.168.42.120:631/printers/Kyocera_FS-1220MFP

ou, si l'adresse change, via son nom réseau : ipp://um560.local:631/printers/Kyocera_FS-1220MFP

Avant de commencer (prérequis)

  • Le PC um560 doit être allumé et éveillé (c'est lui le serveur d'impression).
  • L'appareil (Chromebook, PC, téléphone) doit être sur le même réseau que um560 (Wi-Fi ou câble).
  • Aucun pilote à télécharger : on utilise l'impression réseau standard (IPP / AirPrint / Mopria).

1 Chromebook

  1. Connecte-toi au même Wi-Fi que um560.
  2. Ouvre Paramètres → Imprimantes (ou Périphériques → Imprimantes).
  3. L'imprimante peut apparaître automatiquement sous le nom « Kyocera FS-1220MFP @ um560 ». Si oui, clique dessus, c'est fini.
  4. Sinon, clique sur Ajouter une imprimante (ajout manuel) et saisis l'adresse :
    ipp://192.168.42.120:631/printers/Kyocera_FS-1220MFP
    Puis Ajouter.
  5. Pour imprimer : dans n'importe quelle application, Ctrl + P, choisis Kyocera FS-1220MFP.

2 Windows 10 / 11

  1. Ouvre Paramètres → Bluetooth et appareils → Imprimantes et scanners.
  2. Clique sur Ajouter une imprimante ou un scanner.
  3. Attends la détection. Si l'imprimante n'apparaît pas, clique sur « L'imprimante que je recherche n'est pas dans la liste ».
  4. Sélectionne « Sélectionner une imprimante partagée par son nom » et saisis :
    http://192.168.42.120:631/printers/Kyocera_FS-1220MFP
  5. Clique sur Suivant. Si Windows demande un pilote, choisis Microsoft IPP Class Driver (ou Générique) dans la liste.
  6. Nomme l'imprimante, termine, et coche éventuellement Définir comme imprimante par défaut.
Astuce : dans Chrome / Edge, Ctrl + P fonctionne aussi. Si l'ajout par URL échoue, vérifie que le PC um560 est bien allumé.

3 Android (téléphone / tablette)

  1. Connecte l'appareil au même Wi-Fi que um560.
  2. Active le service d'impression : Paramètres → Connexions / Appareils connectés → Impression → Service d'impression par défaut (ou installe Mopria Print Service depuis le Play Store).
  3. Ouvre un document, une page web ou une photo → menu Partager / Imprimer.
  4. Sélectionne Kyocera FS-1220MFP (détectée automatiquement sur le réseau).

4 iPhone / iPad (AirPrint)

  1. Connecte l'appareil au même Wi-Fi que um560.
  2. Ouvre un document / une page → icône Partager → Imprimer.
  3. Dans Imprimante, sélectionne Kyocera FS-1220MFP (ou l'entrée contenant @ um560).
  4. Règle les options puis touche Imprimer.
AirPrint repose sur la découverte automatique (mDNS). Si l'imprimante n'apparaît pas, vérifie que le Wi-Fi n'isole pas les appareils entre eux (option « isolation client » du routeur).

Dépannage rapide

ProblèmeSolution
Rien ne sort Le PC um560 est-il allumé et sorti de veille ? L'imprimante est branchée dessus.
L'imprimante n'est pas listée Même réseau ? Sinon saisis l'adresse IPP à la main (voir encadré en haut).
L'adresse ne répond plus Utilise le nom um560.local au lieu de l'IP.
Vérifier que le serveur répond Dans un navigateur : http://192.168.42.120:631/printers/Kyocera_FS-1220MFP

Pourquoi passer par um560 ?

Cette Kyocera est une imprimante « hôte » (langage KPSL / GDI) : elle ne comprend ni PostScript ni PCL et n'est donc pas pilotable directement en réseau. Le PC Debian joue le rôle de serveur d'impression : il reçoit les documents en IPP/AirPrint et les convertit en KPSL pour l'imprimante (filtre libre rastertokpsl-re).
